# DNS Leak Prevention Script

اسکریپت Bash برای Ubuntu 22.04 که با راه‌اندازی یک DNS Proxy محلی توسط `dnsmasq`، تنظیم DNS سیستم روی `127.0.0.1` و اجرای چند بررسی ارتباطی، وضعیت DNS سیستم را ارزیابی می‌کند.

> **نسخه اسکریپت:** `7.5`  
> **سیستم‌عامل هدف:** Ubuntu 22.04  
> **سرویس DNS محلی:** `dnsmasq`  
> **DNSهای Upstream:** Cloudflare (`1.1.1.1` و `1.0.0.1`)

## هشدار امنیتی

این اسکریپت تغییرات مهم و سطح پایینی در سیستم‌عامل ایجاد می‌کند و باید با احتیاط اجرا شود.

اسکریپت اقدامات زیر را انجام می‌دهد:

- با سطح دسترسی `root` اجرا می‌شود.
- سرویس `systemd-resolved` را متوقف و غیرفعال می‌کند.
- فایل `/etc/resolv.conf` را بازنویسی می‌کند.
- در پایان روی `/etc/resolv.conf` ویژگی `immutable` قرار می‌دهد.
- پکیج‌های `dnsmasq`، `dnsutils` و `curl` را نصب می‌کند.
- ممکن است تنظیمات قبلی DNS سیستم را تغییر دهد.
- کانتینرهای Docker مشخصی را بر اساس نام متوقف و حذف می‌کند.
- hostname سیستم را در صورت تأیید کاربر تغییر می‌دهد.
- IP عمومی سیستم را برای بررسی موقعیت جغرافیایی به یک سرویس خارجی ارسال می‌کند.

قبل از اجرا:

1. اسکریپت را کامل بررسی کنید.
2. از فایل‌های مهم سیستم backup تهیه کنید.
3. آن را ابتدا روی یک ماشین مجازی یا محیط آزمایشی اجرا کنید.
4. مطمئن شوید حذف کانتینرهای Docker برای شما مشکلی ایجاد نمی‌کند.
5. از آزاد بودن port `53` اطمینان حاصل کنید.
6. برنامه‌ای برای بازگردانی تغییرات داشته باشید.

> این پروژه تضمین نمی‌کند که سیستم شما به‌صورت کامل در برابر DNS Leak، نظارت شبکه، افشای IP یا سایر مشکلات حریم خصوصی محافظت شود.

## معرفی

این اسکریپت برای سیستم‌های Ubuntu طراحی شده است و تلاش می‌کند مسیر Resolve کردن DNS را از طریق یک نمونه محلی از `dnsmasq` مدیریت کند.

روند کلی کار به این شکل است:

1. بررسی می‌کند که اسکریپت با دسترسی `root` اجرا شده باشد.
2. وضعیت hostname سیستم را نمایش می‌دهد و امکان تغییر آن را فراهم می‌کند.
3. سرویس `systemd-resolved` را متوقف می‌کند.
4. برخی کانتینرهای DNS در Docker را شناسایی و حذف می‌کند.
5. فایل `/etc/resolv.conf` را backup می‌گیرد.
6. پکیج `dnsmasq` و ابزارهای موردنیاز را نصب می‌کند.
7. `dnsmasq` را روی `127.0.0.1:53` پیکربندی می‌کند.
8. DNSهای Cloudflare را به‌عنوان DNS بالادستی تنظیم می‌کند.
9. فایل `/etc/resolv.conf` را روی DNS محلی تنظیم می‌کند.
10. چند تست DNS و اتصال انجام می‌دهد.
11. وضعیت نهایی سیستم را در قالب یک جدول نمایش می‌دهد.

### نکته مهم

`dnsmasq` به‌طور معمول DNS Queryها را رمزنگاری نمی‌کند. این اسکریپت VPN، تونل رمزنگاری‌شده، DNS-over-HTTPS یا DNS-over-TLS ایجاد نمی‌کند.

## قابلیت‌ها

- بررسی اجرای اسکریپت با دسترسی `root`
- نمایش نسخه سیستم‌عامل و نسخه اسکریپت
- امکان تغییر hostname
- توقف و غیرفعال‌سازی `systemd-resolved`
- ایجاد backup از `/etc/resolv.conf`
- شناسایی Docker در صورت نصب بودن
- حذف کانتینرهای مشخص با نام‌های زیر:

  - `cloudflared`
  - `dnsmasq`
  - `pihole`
  - `adguard`
  - `unbound`

- نصب پکیج‌های زیر:

  - `dnsmasq`
  - `dnsutils`
  - `curl`

- ایجاد پیکربندی اختصاصی برای `dnsmasq`
- تلاش برای اجرای `dnsmasq` از چند روش مختلف
- بررسی listening بودن port `53`
- تنظیم DNS سیستم روی `127.0.0.1`
- تست Resolve کردن دامنه‌ها با `dig`
- تلاش برای تشخیص IP عمومی سرور
- مقایسه IP به‌دست‌آمده از Resolverهای مختلف
- بررسی تقریبی کشور IP عمومی
- نمایش وضعیت سرویس DNS
- نمایش وضعیت Docker و کانتینرهای حذف‌شده
- ارائه Exit Code موفق یا ناموفق
